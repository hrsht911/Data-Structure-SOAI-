# Data Structures — Practical College Work 📚

Official repository tracking my practical lab exercises, problem-solving assignments, and code implementations for the **Data Structures** course at MIT ADT University (B.Tech AI/ML).

---

## 📌 About This Repo
* **Purpose:** A centralized repository to log and store all hands-on coding assignments, laboratory experiments, and practical logic implementations assigned throughout the semester.
* **Focus:** Understanding fundamental data structures, memory management, time and space complexity, and practical problem-solving.
* **Approach:** Writing clean, compilation-ready C++ code to convert theoretical data structure concepts into working practical applications.

---

## 🧠 Core Topics & Learning Scope

This repository houses code covering core foundational concepts:

* **Linear Data Structures:** Arrays, Dynamic Memory Allocation, Stacks, Queues, and Linked Lists.
* **Non-Linear Data Structures:** Trees, Binary Search Trees (BST), Heaps, and Graphs.
* **Searching & Sorting Algorithms:** Linear Search, Binary Search, Bubble Sort, Insertion Sort, Selection Sort, Quick Sort, and Merge Sort.
* **Practical Applications:** Menu-driven CLI programs, state tracking, token management systems, and real-world logic implementations.

---
